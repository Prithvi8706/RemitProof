## 1. Objective and rationale

Record four known false-authorization paths (F2, F2 residual, F3, F4) as tests that state the safe behaviour. Each fails today and is marked as a strict expected failure. Add control tests that pin each fixture, so a probe can fail only for the reason it documents.

Why: the findings exist only in scratch scripts. Once they are in the suite, a later fix cannot land without someone removing the marker on purpose, and a regression cannot hide (INV-05, INV-06, INV-07, INV-P8).

You are not fixing anything in this task. The probes must fail.

## 1. Objective and rationale

Nothing detects a consistent overwrite today. Every later measurement depends on these files staying byte-stable (INV-P1, DD-14).

## 6. Input and output contracts

**`default_manifest_path(repo_root)`** returns `repo_root / "audit" / CURRENT_FREEZE_GENERATION / "frozen_inputs.json"`.

**`normalized_sha256(path)`** reads the file as bytes, replaces every `b"\r\n"` with `b"\n"`, and returns the lowercase hex SHA-256 of the result.

**`build_manifest(repo_root)`** returns a dictionary with exactly these six keys:

| Key | Value |
| --- | --- |
| `manifest_format_version` | `MANIFEST_FORMAT_VERSION` |
| `freeze_generation` | `CURRENT_FREEZE_GENERATION` |
| `hash` | `HASH_DESCRIPTION` |
| `roots` | `list(FROZEN_ROOTS)` |
| `file_count` | Number of entries in `files` |
| `files` | Mapping from POSIX-style path relative to `repo_root` to `normalized_sha256`, with keys in ascending order |

**`diff_manifests(expected, actual)`** compares the two `files` mappings (a missing `files` key counts as empty) and returns exactly `{"added": [...], "removed": [...], "changed": [...]}`. `added`: in actual only. `removed`: in expected only. `changed`: in both with different hashes. Each list is sorted ascending.

**`manifest_bytes(manifest)`** returns `(json.dumps(manifest, indent=2, sort_keys=True) + "\n").encode("utf-8")`.

**`main(argv)`** command line:

| Argument | Meaning |
| --- | --- |
| `--write` or `--check` | Exactly one is required (mutually exclusive group, `required=True`) |
| `--repo-root PATH` | Default `str(REPO_ROOT)` |
| `--manifest PATH` | Default: `default_manifest_path` of the resolved repo root |
| `--force` | Allows `--write` to replace an existing manifest |

Behaviour and exit codes:

| Mode | Situation | Printed line | Return |
| --- | --- | --- | --- |
| `--write` | Manifest exists, no `--force` | `refusing to overwrite <path>; pass --force after review` | `EXIT_USAGE` |
| `--write` | Otherwise | `wrote <path> (<file_count> files)` | `EXIT_OK` |
| `--check` | Manifest file missing | `manifest is missing: <path>` | `EXIT_USAGE` |
| `--check` | Any list in the diff is non-empty | The diff as `json.dumps(diff, indent=2, sort_keys=True)` | `EXIT_DRIFT` |
| `--check` | No difference | `frozen inputs match <path> (<file_count> files)` | `EXIT_OK` |

`--write` uses `atomic_write_bytes(manifest_path, manifest_bytes(actual))`. `--check` never writes.

## 8. Algorithm

```
build_manifest(repo_root):
    files = {}
    for root in FROZEN_ROOTS:
        root_path = repo_root / root
        if root_path is not a directory:
            raise FileNotFoundError("frozen root is missing: " + root)
        for path in sorted(root_path.rglob("*")):
            if path is not a file: continue
            relative = path.relative_to(repo_root)
            if _is_ignored(relative): continue
            files[relative.as_posix()] = normalized_sha256(path)
    return the six-key dictionary, with files sorted by key

_is_ignored(relative):
    return True if any component of relative starts with "." or equals "__pycache__"
```

## 9. Edge cases and error handling

| Case | Required behaviour |
| --- | --- |
| A frozen root directory is missing | `FileNotFoundError` with the message above. Do not catch it in `main`. |
| A path component starts with `.` (for example `results/generations/.publishing-abc/`, `.DS_Store`) | Ignored |
| `__pycache__` directories | Ignored |
| Empty file | Hashed normally |
| CRLF line endings | Same hash as the LF version |
| Lone `\r` not followed by `\n` | Left unchanged |
| The manifest file itself | Lives under `audit/`, which is not a frozen root, so it is never hashed |

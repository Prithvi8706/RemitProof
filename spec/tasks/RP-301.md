## 1. Objective and rationale

`backend/remitbench/stats.py`: seven public functions, standard library only.

| Function | Used for |
| --- | --- |
| `upper_bound` | "0 wrong in n" stated as a one-sided 95% upper bound, never as 0% |
| `clopper_pearson` | Two-sided exact interval for an error rate |
| `wilson` | Interval for coverage and other proportions |
| `mcnemar_exact` | Two systems compared on the same cases |
| `holm` | Correction across the planned comparisons |
| `cluster_bootstrap` | Intervals that respect that the cases of one seed are not independent |
| `binomial_cdf`, `bootstrap_indices` | Building blocks, public so they can be tested |

Why here and not `backend/app/eval/`, as the first scope note said: the code that uses these functions reads gold labels, and nothing under `backend/app/` may (R-11). All evaluation code lives in `backend/remitbench/`.

Why no SciPy: no new dependency for seven functions, and each is short enough to check against a closed form.

Why no `random` module: the bootstrap must give the same interval on every machine and Python version. Resample indices come from SHA-256.

## 5. Interfaces

```python
Z_95 = 1.959963984540054
BISECTION_STEPS = 200

def binomial_cdf(k: int, n: int, p: float) -> float
def upper_bound(k: int, n: int, alpha: float = 0.05) -> float
def clopper_pearson(k: int, n: int, alpha: float = 0.05) -> Tuple[float, float]
def wilson(k: int, n: int, z: float = Z_95) -> Tuple[float, float]
def mcnemar_exact(b: int, c: int) -> float
def holm(p_values: Sequence[float]) -> List[float]
def bootstrap_indices(group_count: int, resamples: int, seed: str) -> Tuple[Tuple[int, ...], ...]
def cluster_bootstrap(groups: Sequence[Tuple[int, int]], resamples: int = 10000, seed: str = "remitbench-bootstrap-v1", alpha: float = 0.05) -> Optional[Tuple[float, float, int]]
```

Imports: `hashlib`, `math`, `functools.lru_cache`, `typing`. Nothing else. In particular not `random`, `statistics`, `fractions` or anything outside the standard library.

Private helpers: `_check(k, n)`, `_log_pmf(i, n, p)`, `_solve(function, target)`.

## 6. Input and output contracts

### 6.1 Validation

`_check(k, n)`: raise `ValueError("n must be positive")` if `n <= 0`; raise `ValueError("k must be between 0 and n")` if `k < 0` or `k > n`. Called first by `upper_bound`, `clopper_pearson` and `wilson`.

### 6.2 `binomial_cdf(k, n, p)`

P(X <= k) for X distributed Binomial(n, p). In this order: `k < 0` gives `0.0`; `k >= n` gives `1.0`; `p <= 0.0` gives `1.0`; `p >= 1.0` gives `0.0`; otherwise `min(1.0, math.fsum(math.exp(_log_pmf(i, n, p)) for i in range(k + 1)))`.

`_log_pmf(i, n, p)` is `math.lgamma(n + 1) - math.lgamma(i + 1) - math.lgamma(n - i + 1) + i * math.log(p) + (n - i) * math.log1p(-p)`.

Log space, so that large n does not overflow.

### 6.3 `_solve(function, target)`

Bisection on the open interval from 0 to 1 for a function that decreases through `target`. Start with `low = 0.0`, `high = 1.0`. Repeat `BISECTION_STEPS` times: `middle = (low + high) / 2.0`; if `function(middle) > target` then `low = middle`, else `high = middle`. Return `(low + high) / 2.0`. A fixed number of steps, no tolerance test.

### 6.4 Exact bounds

`upper_bound(k, n, alpha)`: `1.0` when `k == n`, otherwise `_solve(lambda p: binomial_cdf(k, n, p), alpha)`. This is the one-sided Clopper-Pearson upper bound.

`clopper_pearson(k, n, alpha)` returns `(lower, upper)`:

- `lower` is `0.0` when `k == 0`, otherwise `_solve(lambda p: binomial_cdf(k - 1, n, p), 1.0 - alpha / 2.0)`.
- `upper` is `1.0` when `k == n`, otherwise `_solve(lambda p: binomial_cdf(k, n, p), alpha / 2.0)`.

### 6.5 `wilson(k, n, z)`

With `share = k / n`, `denominator = 1.0 + z * z / n`, `centre = (share + z * z / (2.0 * n)) / denominator`, `half = z * math.sqrt(share * (1.0 - share) / n + z * z / (4.0 * n * n)) / denominator`: the lower bound is exactly `0.0` when `k == 0`, otherwise `max(0.0, centre - half)`; the upper bound is exactly `1.0` when `k == n`, otherwise `min(1.0, centre + half)`. The two exact cases exist because the formula returns values such as 2.8e-17 and 0.9999999999999999 there.

### 6.6 `mcnemar_exact(b, c)`

`b` and `c` are the two discordant counts. Raise `ValueError("discordant counts must not be negative")` if either is negative. With `total = b + c`: return `1.0` when `total == 0`; otherwise `min(1.0, 2.0 * tail / float(2 ** total))` where `tail = sum(math.comb(total, i) for i in range(min(b, c) + 1))`. Two-sided exact binomial test with probability one half. Integer arithmetic until the final division.

### 6.7 `holm(p_values)`

Returns adjusted p-values in the order given. Sort the indices by `(p_values[index], index)`. Walk them with `rank` from 0: `running = max(running, min(1.0, (count - rank) * p_values[index]))`, and store `running` at `index`. `running` starts at `0.0`. An empty input returns an empty list.

### 6.8 `bootstrap_indices(group_count, resamples, seed)`

Decorated with `@lru_cache(maxsize=8)`. Returns `resamples` rows, each a tuple of `group_count` integers in `range(group_count)`.

For each `resample` from 0: start an empty row and `block = 0`. While the row is short: `digest = hashlib.sha256(f"{seed}:{resample}:{block}".encode("utf-8")).digest()`; for `offset` in `(0, 8, 16, 24)`, if the row is still short, append `int.from_bytes(digest[offset:offset + 8], "big") % group_count`; then `block += 1`.

### 6.9 `cluster_bootstrap(groups, resamples, seed, alpha)`

`groups` holds one `(numerator, denominator)` pair per cluster, in an order the caller fixes. The statistic is the sum of numerators divided by the sum of denominators.

1. Empty `groups`: return `None`.
2. For each row of `bootstrap_indices(len(groups), resamples, seed)`: sum the numerators and the denominators of the indexed groups. If the denominator sum is positive, keep the ratio. Otherwise drop this resample.
3. No ratio kept: return `None`.
4. Sort the kept ratios. `low = values[int(math.floor((alpha / 2.0) * len(values)))]`. `high = values[int(math.ceil((1.0 - alpha / 2.0) * len(values))) - 1]`.
5. Return `(low, high, len(values))`.

The third element says how many resamples had a defined ratio. A caller that reports the interval reports that number with it.

## 9. Edge cases and error handling

| Case | Required behaviour |
| --- | --- |
| `n == 0` in a bound or an interval | `ValueError`. The caller decides what an empty stratum shows. |
| `k == 0` | Lower bound exactly `0.0` |
| `k == n` | Upper bound exactly `1.0` |
| No discordant pair in McNemar | `1.0` |
| Every group has denominator 0 | `cluster_bootstrap` returns `None` |
| Some resamples have denominator 0 | Dropped, and the count of kept resamples is returned |
| A group count that is not a power of two | The modulo has a bias below 2 to the power of minus 50. Accepted. |

None affected. No runtime code changes. The module's own correctness is shown by known answers: closed forms for zero events, tail probabilities recomputed at the returned bounds, and hand-computed McNemar and Holm values.
